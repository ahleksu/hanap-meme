# Assets and rights

## Code
The code in this repository is MIT licensed. See `LICENSE`.

## Scraped images
- Scraped images are NOT covered by the MIT license, and they are not included in this repository.
- The maintainer does not own scraped images. Rights stay with their creators.
- Per-image provenance (source URL, platform, author, retrieval date) lives in `catalog.json`.
- This is not a rights-cleared collection. Every scraped image has the rights status "unverified".
- Each person who runs HanapMeme builds their own image library on their own machine with `npm run ingest`.

## AI-generated templates
- The template backgrounds in `public/templates/` are original images made with an OpenAI image model.
- They show fictional people only, with no real people and no logos. They are included in this repository.
- The Anton font in `assets/fonts/` is under the SIL Open Font License 1.1. See `assets/fonts/OFL.txt`.

## Removal requests
- Removal requests are honored within 48 hours, no questions asked.
- On a running site, click Report on any image, or use the [takedown form](/takedown). The image is hidden at once from the website, the REST API, and MCP.
- For this repository, open a [takedown request issue](https://github.com/ahleksu/hanap-meme/issues/new?template=takedown_request.md).
